# Lav Shoes — Custos, estoque, serviços e lucro

App de gestão para lavanderia de tênis: calcula o custo por par de cada material, controla o estoque, define o preço dos serviços e mostra o lucro.

## Como usar

Abra o arquivo `index.html` no navegador (celular ou computador). Não precisa instalar nada.

Para ter um link público, ative o **GitHub Pages**: *Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save*.

## O que tem

- **Painel:** meta do mês, lucro por par, equilíbrio e alertas.
- **Materiais:** custo, rendimento e custo por par; quantidade em L, mL, kit e outras unidades; categorias (Limpeza, Finalização, Pintura, Colagem, Embalagens e Outra).
- **Estoque:** contagem, mínimo, cobertura em dias e lista de compras.
- **Serviços:** preço, tempo, materiais usados, margem e preço sugerido.
- **Pedidos:** em breve.

## Seus dados

Fora do Claude, os dados ficam salvos só no navegador do aparelho em que você usa o app. Cada aparelho começa com os exemplos e não sincroniza com os demais.
